FVM Implementation procedure

1. Read in .gri file (mesh)
2. Initialize soluition or read in a state from a file (ASCII or Binary format)
3. Prepare data structures (normal vectors, areas, centroids)
    V, E2N --edgehash --> IE, BE ---> In, Bn, Area, centroid 
4. Loop over time steps 
    a. call residual function (multiple times)
    b. set a time step (from the first residual eval, CFL condition)
    c. advance state forward in time
    d. check residual if marching to steady state 
    e. return to b
